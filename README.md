# Fernn

This is my first ever website built using HTML, CSS, and JavaScript. Before writing any code, I designed the initial layout on Canva to visualize how it might look, and then worked on bringing that design into reality with code.

Pages in this Website

Home Page
The landing page of the website. It introduces the site and gives a first impression of the layout, styling, and navigation. It contains the main header, a brief introduction section, and links to the other pages.

About Page
A page dedicated to describing the purpose of the website or providing information about me as the creator. It explains the background, motivation, and vision behind building the project.

Contact Page
A page where visitors can find details to get in touch. It includes a simple contact form built with HTML and styled with CSS. The form currently does not send data to a server but serves as a placeholder for future improvements such as connecting to an API or backend.

Gallery / Showcase Page
A section that highlights visual content such as images, designs, or sample work. It demonstrates how media elements can be displayed in a clean and structured layout using CSS styling.
